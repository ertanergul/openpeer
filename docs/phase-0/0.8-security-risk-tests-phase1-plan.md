## 3. Test Strategy

- **Layers:** `Unit` (slot generation, state transitions, calculations), `Feature` (HTTP + Policies + Fortify flows), `Concurrency` (real PostgreSQL; two-PDO-connection technique; global test transaction wrapping **disabled**) — `C1–C8` from 0.6 — and `Smoke` (docker boot + migration + app healthcheck).
- **Database:** tests run against **PostgreSQL 17** (`phpunit.xml` → `DB_CONNECTION=pgsql`); SQLite does not validate this constraint set (D-04) — no exceptions granted. Parallel runs use per-process DBs (Laravel `ParallelTesting` suffix) — verified in 1.6.
- **Pest organization:** `describe()` + `expect()`; folders `tests/Feature/<Module>/` + `tests/Feature/Concurrency/` (0.3 structure).
- **Architecture tests (pest-plugin-arch):** enforce 0.3 module boundaries — forbid cross-module `\Models\` imports; forbid direct Model mutation from controllers; keep controllers thin.
- **Quality gates:** `composer test` (Pint `--dirty` + PHPStan/Larastan + Pest), `vp check` + `tsc --noEmit`; `MockPaymentGateway` production-guard test; webhook deduplicate test.
- **CI (GitHub Actions):** POST-MVP, separate approved task (matrix row 44). Until then quality gates run locally-only.
